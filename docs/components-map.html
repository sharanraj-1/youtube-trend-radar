YouTube Trend Radar · Components Map

Live YouTube data is collected every Sunday at 5 AM, grouped and ranked in plain code, and delivered as a step-by-step brief before 11 AM, so Ishaan knows what to film this week. Gemini Flash reads titles and writes the words; it never decides.

The Cut

The AI never decides what's trending. Gemini only labels titles and writes the words; plain code finds the trends, ranks them and fact-checks every sentence. Every number comes straight from YouTube, and the AI isn't allowed to write any.

Humans stay here

  • Ishaan decides what to film; the brief only recommends
  • He picks the topics and peer channels to track
  • Every "film / maybe / skip" call is his alone

Never miss a Sunday

  • A step that fails 3× still publishes a partial brief
  • Run stalls? GitHub Actions and open tabs resume it
  • No brief by 9:30 AM → backup brief + Telegram alert
  • 107 automated tests cover scoring, trends and fact-checks
